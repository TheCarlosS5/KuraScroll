# Sprint 81 QA Resilience Matrix: Multi-Angle Reading Projection Engine

## Executive Summary
Sprint 81 introduces the **Multi-Angle Reading Projection Engine**, enabling readers to apply 3.5D perspective tilts, keystone corrections, and pitch/yaw transformations to manga pages for ergonomic tablet or desktop viewing angles without overloading legacy hardware (Intel Pentium T4500, Intel GMA 4500MHD).

This document establishes exhaustive test plans, edge-case fuzzing matrices, and failure recovery protocols for out-of-bounds pitch, yaw, perspective distance, keystone ratio clamping, and ETag 304 caching.

## 2. Vitest Test Suite Specifications

### 2.1 Backend / Fastify Projection Service & Clamping Unit Tests (`tests/unit/backend/services/projection-service.test.ts`)
```typescript
import { describe, it, expect } from 'vitest';
import { clampPitch, clampYaw, clampPerspectiveDistance, clampKeystoneRatio, computeProjectionEtag } from '../../../../src/backend/services/projection-service';

describe('Multi-Angle Reading Projection Engine Resilience & Clamping', () => {
  it('clamps out-of-bounds pitch values to [-35, +35]', () => {
    expect(clampPitch(-90)).toBe(-35);
    expect(clampPitch(180)).toBe(35);
    expect(clampPitch(15)).toBe(15);
  });

  it('clamps out-of-bounds yaw values to [-25, +25]', () => {
    expect(clampYaw(-120)).toBe(-25);
    expect(clampYaw(90)).toBe(25);
    expect(clampYaw(-10)).toBe(-10);
  });

  it('clamps perspective distance edge cases to [400, 2000]', () => {
    expect(clampPerspectiveDistance(0)).toBe(400);
    expect(clampPerspectiveDistance(-500)).toBe(400);
    expect(clampPerspectiveDistance(10000)).toBe(2000);
    expect(clampPerspectiveDistance(800)).toBe(800);
  });

  it('clamps keystone ratio values to [0.0, 1.0]', () => {
    expect(clampKeystoneRatio(-0.5)).toBe(0.0);
    expect(clampKeystoneRatio(1.5)).toBe(1.0);
    expect(clampKeystoneRatio(0.45)).toBe(0.45);
  });

  it('generates deterministic ETags for cached projection matrices', () => {
    const etag1 = computeProjectionEtag(10, 5, 800, 0.2);
    const etag2 = computeProjectionEtag(10, 5, 800, 0.2);
    expect(etag1).toBe(etag2);
    expect(etag1).toMatch(/^"[\da-f]+"$/);
  });
});
```

## 3. Failure Recovery & Edge Case Guidelines

1. **Hardware Acceleration Fallback:** On legacy hardware lacking robust hardware 3D compositing (Intel GMA 4500MHD), complex perspective matrices fall back to 2D CSS skew transformations to maintain smooth frame rates.
2. **Transform Sanitization:** Any incoming matrix transformation values containing `NaN` or `Infinity` are automatically scrubbed and reset to identity defaults.
