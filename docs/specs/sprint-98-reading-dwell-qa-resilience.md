# Sprint 98 QA Resilience Matrix: Predictive Intelligent Pre-Reading Micro-Heatmap Dwell Predictor (SLA 62)

## Executive Summary
Sprint 98 introduces the **Predictive Intelligent Pre-Reading Micro-Heatmap Dwell Predictor (SLA 62)**, designed to predict reader dwell time on upcoming manga pages and panels based on visual complexity, dialogue density, and historical reading cadence, driving intelligent pre-caching and pre-flight cache warming.

This document establishes exhaustive test plans, edge-case fuzzing matrices, and failure recovery protocols for contemplative/absent readers (`elapsedMs > predictedTotalDwellMs`), strict parameter clamping for dwell weights and urgency thresholds, invalid mode fallbacks, Fastify idempotency, and ETag 304 caching.

## 2. Vitest Test Suite Specifications

### 2.1 Backend / Fastify Dwell Predictor Service & Unit Tests (`tests/unit/backend/services/dwell-predictor-service.test.ts`)
```typescript
import { describe, it, expect } from 'vitest';
import { calculateRemainingDwell, clampDwellParameters, sanitizeDwellMode, computeDwellEtag } from '../../../../src/backend/services/dwell-predictor-service';

describe('Dwell Predictor Engine Resilience & Clamping', () => {
  it('saturates remaining dwell to 0 without negative underflows when elapsed > predicted', () => {
    const remaining = calculateRemainingDwell(15000, 5000);
    expect(remaining).toBe(0);
    expect(Number.isFinite(remaining)).toBe(true);
  });

  it('clamps base dwell, complexity weight, and urgency thresholds strictly', () => {
    const clamped = clampDwellParameters({ baseDwellMs: -200, complexityWeight: 10.0, urgencyThresholdMs: 50 });
    expect(clamped.baseDwellMs).toBe(500);         // Min safe bound
    expect(clamped.complexityWeight).toBe(5.0);    // Max safe bound
    expect(clamped.urgencyThresholdMs).toBe(200);  // Min threshold bound
  });

  it('falls back to "cadence_adaptive" on invalid prediction modes', () => {
    expect(sanitizeDwellMode('ml_predictive')).toBe('ml_predictive');
    expect(sanitizeDwellMode('quantum_speedread')).toBe('cadence_adaptive');
    expect(sanitizeDwellMode(null)).toBe('cadence_adaptive');
  });

  it('generates deterministic ETags for cached dwell profile endpoints', () => {
    const etag1 = computeDwellEtag('series-777', 2500, 1.2);
    const etag2 = computeDwellEtag('series-777', 2500, 1.2);
    expect(etag1).toBe(etag2);
    expect(etag1).toMatch(/^"[\da-f]+"$/);
  });
});
```

## 3. Failure Recovery & Edge Case Guidelines

1. **Underflow Protection:** All timer and dwell countdown formulas use explicit `Math.max(0, target - elapsed)` wrappers to guarantee zero negative underflow anomalies.
2. **Idempotency Guarantee:** Telemetry POST endpoints use request deduplication keys to ensure robust resilience over flaky mobile connections.
